# آية قرآنية (Aya Qurania) – تطبيق أندرويد تجريبي
المشروع مستقل برمز حزمة com.ayaqurania.calls، وعلى فرع منفصل ولا يغير كود VIB في الفرع main.

الخصائص: إنشاء روابط مكالمات صوت وفيديو Jitsi، حفظ الأشخاص والمجموعات على الهاتف، دعوات ومشاركة الروابط. ليس تطبيق مكالمات كاملة داخل التطبيق؛ لا توجد رنة مكالمة واردة، ولا تسجيل دخول ولا إضافة أشخاص سحابية. المضيف قد يحتاج تسجيل الدخول لخدمة Jitsi، والمكالمات تحتاج إنترنت. APK تصحيح/debug للتجربة وليس للإنتاج.
